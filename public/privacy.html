YOUR DATA MATTERS

Privacy notice

This website is designed to explain Pomas and help people find official downloads and support. It does not currently run its own account system, analytics platform or feedback database.

Information handled by this website

The site does not intentionally collect or store personal information on a Pomas-owned server. Your browser requests public release information from GitHub to show available versions, installer links and release metadata.

Feedback and support

The feedback form prepares a draft GitHub Issue. You review and submit it on GitHub, which may require an account. GitHub processes the information under its own privacy policy. An email address is optional. Do not submit passwords, authentication tokens, private farm records, database files or customer information.

Downloads

Application installers are hosted through GitHub Releases. GitHub processes the download request; this website does not receive or store the installer.

Cookies and analytics

This version does not embed analytics or advertising scripts and does not use cookies for tracking. The light/dark theme preference exists only in page memory and is not saved.

External websites

Links to GitHub and the ENJ0Y portfolio lead to external websites with their own privacy practices.

Changes to this notice

This notice must be reviewed if the website adds analytics, cookies, accounts, a backend feedback endpoint or other data collection.
